Nout is a compact, offline-first note-taking web app. It combines a polished UI with a rich-text editor so you can create, organize and edit notes with no backend required. Notes stay in your browser, and you can optionally sign in with Google to sync them across devices.

## Features

- Rich-text editor with highlights, code blocks with syntax highlighting, and smilie replacement
- Scratchpad for quick notes that saves automatically
- Folders to organize notes
- Favorites, and the option to hide sensitive notes from the All-notes list
- Search within Notes, Favorites and Folders
- Trash with restore and automatic purge after 30 days
- Works offline; optional cloud sync through Google sign-in keeps notes, folders, scratchpad and accent color in step across devices
- Accent color themes: pick a preset or any custom color and the whole UI follows it
- Responsive layout: sidebar on desktop, drill-down navigation with a bottom tab bar on phone
- Dark theme
